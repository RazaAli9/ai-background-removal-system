# Publishing Checklist

Before making the repository public:

- [ ] Confirm you are allowed to publish the internship/project source code.
- [ ] Review `git diff --cached` / staged files before the first push.
- [ ] Confirm `.env`, tokens, logs, model weights, private images, and generated outputs are absent.
- [ ] Add 3-5 representative before/after examples that you have permission to publish.
- [ ] Add the live Hugging Face Space link.
- [ ] Add a short demo GIF or screenshot to `assets/`.
- [ ] Decide whether to keep default copyright (no license) or add an explicit license for your original code.
- [ ] Add formal quality metrics only after running a fixed evaluation set.
